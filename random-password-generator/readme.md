# 🔐 Random Password Generator

A simple Python script that generates strong passwords with a minimum length of 6 characters. The password comprises a mix of **alphabets, digits, and punctuation** to ensure security.

## 🚀 Features
- Generates a strong password with random **uppercase and lowercase letters, numbers, and special characters**.
- Ensures a minimum password length of **6 characters** for better security.
- Simple **user-friendly CLI interaction**.

## 🛠️ How to Use
1. **Clone the Repository**
   ```bash
   git clone https://github.com/aaryanshlok0/python-mini-projects.git
   ```
2. **Navigate to the Project Directory**
   ```bash
   cd python-mini-projects/password-generator
   ```
3. **Run the Script**
   ```bash
   python password_generator.py
   ```
4. **Enter the desired password length** (must be 6 or more).
5. **Get your randomly generated strong password!**
