# Snake, Water, Gun Game 🐍💧🔫

This is a simple command-line game of **Snake, Water, and Gun** where the user plays against the computer. The first to reach 3 points wins! 🎮

## Rules
- **Snake beats Water** 🐍 > 💧
- **Water beats Gun** 💧 > 🔫
- **Gun beats Snake** 🔫 > 🐍
- First to **3 points** wins the game.

## How to Play
1. Run the Python script.
2. Enter your name when prompted.
3. Choose between:
   - `1` for Snake 🐍
   - `2` for Water 💧
   - `3` for Gun 🔫
4. The computer will randomly choose its option.
5. The winner of each round is decided based on the rules.
6. The first to **3 points** wins the match!

## Installation
1. Ensure you have **Python 3** installed.
2. Download the `snake_water_gun.py` file.
3. Open a terminal or command prompt and run:
   ```sh
   python snake_water_gun.py
   ```
